# `packages/langchain-lab/src`

这里存放 LangChain.js 学习轨的概念 demo，按 Topic 顺序使用“需求注释 → user 理清思路 → 明确确认后实现”的两阶段流程。

- 完整学习路线、每题深度和自检题：[`../LEARNING.md`](../LEARNING.md)
- 进度表、计划文件结构和运行方式：[`../README.md`](../README.md)
